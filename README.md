# Viaje a Bélgica, 8-11 octubre 2026

Guía móvil del viaje Madrid, Bruselas, Gante, Brujas, Madrid. Una sola página estática (`index.html`), sin build.

- Itinerario por días con bloque "Siguiente" según la hora del dispositivo.
- Trenes, comida, historia de cada visita y lista de pendientes.
- Modo claro y oscuro automático.

Abrir `index.html` en el navegador, o servir la carpeta con `python3 -m http.server`.

`PRODUCT.md` recoge el contexto de producto usado para el diseño.
